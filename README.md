# Local source archive for BaseballbettingEdge

This backup branch contains inactive source variants under `snapshots/`. It is not a merged application or a deployable release. Original Git histories, indexes, branches and files are preserved in their original locations. Current and historical variants are deliberately separate. `BACKUP-MANIFEST.json` records aliases, exact original commit pins and exclusions. Some tests need excluded fixture material before they can run; this archive is not claimed complete runtime evidence.

Publication is held pending current Netlify and Render trigger evidence. No remote is configured here. No root workflow or deployment configuration is active. Do not merge this archive into a production branch or execute its archived commands without review.
